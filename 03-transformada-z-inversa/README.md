# Transformada Z Inversa y Respuesta Temporal Discreta
> **MEC36 - Control II | Institución Universitaria de Barranquilla (IUB)**
> **Módulo:** Semana 03 — *Integral de Cauchy, Fracciones Parciales X(z)/z, Polos Complejos y División Directa*

Plataforma institucional interactiva por capítulos (Three.js + Plotly + KaTeX) para regresar del plano Z al tiempo discreto x[k]. Incluye laboratorios de polos complejos conjugados, relieve 3D |Y(z)| con contorno de Cauchy, caso del brazo robótico, 8 actividades con corrección inmediata, tema claro/oscuro y progreso local.

Esta carpeta es la **versión compilada** (Vite) del proyecto fuente
`Cerebro_Docente_Control_II/generacion/web_transformada_z_inversa/`. No se edita aquí:
los cambios se hacen en el proyecto fuente y se publican con `python src/sincronizar_web_repo.py`.
