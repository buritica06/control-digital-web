# Transformada Z Inversa: Fracciones Parciales y Métodos Numéricos 3D
> **MEC36 - Control II | Institución Universitaria de Barranquilla (IUB)**  
> **Módulo:** Semana 03 — *Descomposición de Heaviside, División Larga y Residuos de Cauchy*

## Descripción del Módulo
Entorno computacional interactivo para la recuperación analítica y numérica de secuencias en el tiempo x[k] a partir de funciones racionales X(z). Incluye cálculo paso a paso, visualizador orbital Three.js del plano complejo Z y análisis de estabilidad.

## Tecnologías y Herramientas Utilizadas
- **Visualización 3D:** Three.js / Plotly.js / WebGL
- **Diseño Web y HUD:** Tailwind CSS (Dark Mode espacial)
- **Formulación Matemática:** KaTeX ($\LaTeX$ en navegador a 60 FPS)
- **Generación Matemática:** Python (semana03_3d_experience.py)
