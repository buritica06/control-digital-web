# Ecuaciones en Diferencias: Plataforma Interactiva 3D/2D
> **MEC36 - Control II | Institución Universitaria de Barranquilla (IUB)**
> **Módulo:** Semana 04 — *Plano z, Superficie |G(z)|, Lugar de Raíces 3D, Bode, Nyquist y Espacio de Estados*

Plataforma por capítulos (Three.js + Plotly + KaTeX + math.js) con representación, discretización ZOH, solución paso a paso con respuesta libre y forzada, aplicaciones en control digital, 9 ejercicios con verificación automática y 3 ejemplos resueltos. Progreso guardado, tema claro/oscuro y versión móvil.

Esta carpeta es la **versión compilada** (Vite) del proyecto fuente
`Cerebro_Docente_Control_II/generacion/web_ecuaciones_vite/`. No se edita aquí:
los cambios se hacen en el proyecto fuente y se publican con `python src/sincronizar_web_repo.py`.
