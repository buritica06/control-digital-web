# Topología Energética 3D de la Transformada Z
> **MEC36 - Control II | Institución Universitaria de Barranquilla (IUB)**  
> **Módulo:** Tópico Avanzado — *Mapeo del Plano Complejo S al Plano Z y Círculo Unitario*

## Descripción del Módulo
Superficie tridimensional inmersiva de la magnitud |X(z)| y fase de la Transformada Z. Permite explorar visualmente el Círculo Unitario (|z|=1), las trayectorias de polos/ceros y la relación directa con la estabilidad de sistemas en tiempo discreto.

## Tecnologías y Herramientas Utilizadas
- **Visualización 3D:** Three.js / Plotly.js / WebGL
- **Diseño Web y HUD:** Tailwind CSS (Dark Mode espacial)
- **Formulación Matemática:** KaTeX (LaTeX en navegador a 60 FPS)
- **Generación Matemática:** Python (z_transform_3d_experience.py)
