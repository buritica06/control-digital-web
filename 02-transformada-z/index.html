Deducción desde el Muestreo, Definición Formal y ROC

Bloques 1 y 2 del Temario · 65 minutos · Ogata (Cap. 2) & Franklin (Cap. 2)

1.1 Del Tren de Impulsos al Cambio de Variable $z = e^{sT}$

Bloque 1

Al muestrear una señal continua $x(t)$ mediante un tren de impulsos ideales de Dirac cada $T$ segundos se obtiene la señal modulada en impulsos $x^*(t) = \sum_{k=0}^{\infty} x(kT)\,\delta(t - kT)$. Al aplicar la Transformada de Laplace unilateral:

ECUACIÓN
$$\mathcal{L}\{x^*(t)\} = \sum_{k=0}^{\infty} x(kT)\,e^{-skT}$$

La presencia del término trascendente $e^{-sT}$ complica el análisis algebraico en el plano $s$. Para superar esta dificultad se define el cambio de variable conforme [1]:

$$z = e^{sT} \iff z^{-1} = e^{-sT} \qquad \left(s = \frac{1}{T}\ln z\right)$$

donde el operador $z^{-1}$ representa operativamente el retardo temporal de una muestra ($T$ segundos).

1.2 Transformada Z Unilateral y Región de Convergencia (ROC)

Bloque 2

Para una secuencia causal $x[k] = x(kT)$ ($x[k] = 0$ para $k < 0$), la **Transformada Z unilateral** se define como la serie de potencias complejas [1]:

ECUACIÓN
$$X(z) = \mathcal{Z}\{x[k]\} = \sum_{k=0}^{\infty} x[k]\,z^{-k} = x[0] + x[1]z^{-1} + x[2]z^{-2} + \dots$$

La serie converge en la región del plano complejo donde la suma es finita. Para secuencias causales acotadas, la **Región de Convergencia (ROC)** corresponde al exterior de un círculo de radio $R$:

$$\text{ROC}: \quad |z| > R = \lim_{k\to\infty} \left| \frac{x[k+1]}{x[k]} \right| = \max_{i} |p_i|$$

En el Visor 3D: La corona verde (`#34D399` / `#3B9C6D`) muestra $|z| > R$ y el disco interior (`#F87171`) la región divergente $|z| \le R$.

Transformada Z de Funciones Elementales

Bloque 3 del Temario · 45 minutos · Haz clic en cualquier tarjeta para cargarla en el Visor 3D

1. Función Impulso Unitario (Kronecker Delta) ROC: Todo z

Secuencia activa únicamente en el instante inicial $k = 0$: $x[k] = \delta[k] = 1$ para $k=0$ y $0$ para $k \ne 0$.

$$x[k] = \delta[k] = \begin{cases} 1, & k=0 \\ 0, & k \ne 0 \end{cases} \implies X(z) = 1 \quad (\forall z)$$
2. Función Escalón Unitario ($u[k] = 1$ para $k \ge 0$) ROC: |z| > 1

Secuencia constante $u[k] = 1$ para $k \ge 0$. Suma geométrica de razón $z^{-1}$:

$$X(z) = \sum_{k=0}^{\infty} 1 \cdot z^{-k} = \frac{1}{1 - z^{-1}} = \frac{z}{z - 1} \quad (|z| > 1)$$
3. Función Exponencial / Geométrica ($x[k] = a^k$) ROC: |z| > |a|

Para $x(t) = e^{-at}$ muestreada cada $T$, se define $a^k = (e^{-aT})^k$:

$$X(z) = \sum_{k=0}^{\infty} (a z^{-1})^k = \frac{1}{1 - a z^{-1}} = \frac{z}{z - a} \quad (|z| > |a|)$$
4. Función Rampa Unitaria ($x[k] = kT$) ROC: |z| > 1

Obtenida mediante diferenciación en $Z$ aplicada al escalón unitario:

$$X(z) = \sum_{k=0}^{\infty} k T z^{-k} = -T z \frac{d}{dz}\left(\frac{z}{z - 1}\right) = \frac{T z}{(z - 1)^2} \quad (|z| > 1)$$

Señal Discreta de Error de Servomecanismo

En un sistema de posicionamiento mecatrónico, la señal de error ante una entrada escalón se modela analíticamente en tiempo continuo como:

$$e(t) = 4 e^{-2t} - 3 e^{-5t} \quad (t \ge 0), \qquad f_s = 10\text{ Hz } (T = 0.1\text{ s})$$
1. Secuencia temporal muestreada $e[k] = e(kT)$
$$e[k] = 4\left(e^{-0.2}\right)^k - 3\left(e^{-0.5}\right)^k = 4(0.81873)^k - 3(0.60653)^k$$
2. Cálculo de la Transformada Z ($E(z)$)
$$E(z) = \frac{4z}{z - 0.81873} - \frac{3z}{z - 0.60653} = \frac{z(z + 0.02997)}{z^2 - 1.42526z + 0.49658}$$
3 y 4. Verificación por Teoremas de Valor Inicial y Valor Final
$$e[0] = \lim_{z \to \infty} E(z) = 1 \qquad \text{y} \qquad e[\infty] = \lim_{z \to 1} (1 - z^{-1})E(z) = 0$$

Análisis Comparativo: Laplace vs. Transformada Z

Propiedad Transformada de Laplace (Tiempo Continuo) Transformada Z (Tiempo Discreto)
Definición $\displaystyle \int_0^{\infty} x(t)\,e^{-st}\,dt$ $\displaystyle \sum_{k=0}^{\infty} x[k]\,z^{-k}$
Operador de retardo $e^{-s\tau}$ (trascendente) $z^{-1}$ (racional, algebraico)

Implementación Computacional en Python con SymPy

Bloque 7 del Temario · 20 minutos · Verificación simbólica reproducible

import sympy as sp

def calcular_transformada_z_simbolica():
    """
    Deducción y verificación de la Transformada Z y teoremas usando cálculo simbólico.
    Módulo: MEC36 - Control II (Semana 2) | Institución Universitaria de Barranquilla (IUB)
    """
    k, z, T = sp.symbols('k z T', positive=True)
    
    # Parámetros del caso de estudio
    T_val = 0.1
    a1_val = sp.exp(-2 * T_val)
    a2_val = sp.exp(-5 * T_val)
    
    # Secuencia analítica e[k]
    e_k = 4 * (a1_val)**k - 3 * (a2_val)**k
    
    # Transformadas individuales por definición: Z{a^k} = z / (z - a)
    E_z = 4 * (z / (z - a1_val)) - 3 * (z / (z - a2_val))
    E_z_simplificada = sp.simplify(E_z)
    
    # Evaluación del Teorema del Valor Inicial
    val_inicial = sp.limit(E_z_simplificada, z, sp.oo)
    
    # Evaluación del Teorema del Valor Final
    val_final = sp.limit((1 - 1/z) * E_z_simplificada, z, 1)
    
    print("--- CÁLCULO SIMBÓLICO EN PYTHON (SYMPY) ---")
    print(f"E(z) simplificada : {E_z_simplificada}")
    print(f"Valor inicial e[0]: {float(val_inicial):.4f}")
    print(f"Valor final e[inf]: {float(val_final):.4f}")

if __name__ == "__main__":
    calcular_transformada_z_simbolica()
