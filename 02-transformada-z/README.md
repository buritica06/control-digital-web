# Transformada Z, Funciones Elementales y Teoremas 3D
> **MEC36 - Control II | Institución Universitaria de Barranquilla (IUB)**  
> **Módulo:** Semana 02 — *Fundamentos Teóricos, Región de Convergencia (ROC) y Dinámica Discreta*

## Descripción del Módulo
Visualizador 3D con Three.js y Plotly que calcula y representa geométricamente las Transformadas Z unilaterales de señales canónicas (escalón, rampa, exponencial decreciente, senoidal amortiguada) y los teoremas operacionales de retardo, valor inicial y valor final.

## Tecnologías y Herramientas Utilizadas
- **Visualización 3D:** Three.js / Plotly.js / WebGL
- **Diseño Web y HUD:** Tailwind CSS (Dark Mode espacial)
- **Formulación Matemática:** KaTeX (LaTeX en navegador a 60 FPS)
- **Generación Matemática:** Python (semana02_3d_experience.py)
