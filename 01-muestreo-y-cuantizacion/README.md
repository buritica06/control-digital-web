# Muestreo, Retenedor ZOH y Cuantificación 3D
> **MEC36 - Control II | Institución Universitaria de Barranquilla (IUB)**  
> **Módulo:** Semana 01 — *Arquitectura de Lazo de Control Digital y Discretización Periódica*

## Descripción del Módulo
Laboratorio interactivo y visualizador 3D que modela la conversión analógica a digital (ADC), el teorema de Shannon-Nyquist, el efecto del período de muestreo (T), el retenedor de orden cero (ZOH) y el error de cuantificación con resolución configurable de 8 a 16 bits.

## Tecnologías y Herramientas Utilizadas
- **Visualización 3D:** Three.js / Plotly.js / WebGL
- **Diseño Web y HUD:** Tailwind CSS (Dark Mode espacial)
- **Formulación Matemática:** KaTeX ($\LaTeX$ en navegador a 60 FPS)
- **Generación Matemática:** Python (semana01_3d_experience.py)
